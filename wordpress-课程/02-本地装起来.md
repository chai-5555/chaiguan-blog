# 02 · 第二天：把 WordPress 在自己电脑上跑起来

> 目标：**本机**有一个能登录、能发文章的 WordPress。不上云、不花钱、错了能删。
> 验收：前台能打开站点、后台能登录、发一篇文章能在前台看到。

## 一、为什么先在本地

| 好处 | 说明 |
|---|---|
| 零成本 | 不用买服务器、不用备案 |
| 试错免费 | 装坏了直接删站点重建，2 分钟 |
| 快 | 本地访问没有网络延迟，改 CSS 立刻看到效果 |
| 学得深 | 你能直接看到文件目录、数据库，理解"东西存在哪" |

## 二、四条路怎么选（按你的机器给结论）

| 方案 | 装什么 | 难度 | 适不适合你 |
|---|---|---|---|
| **A. Local（LocalWP）** | 自带 PHP+MySQL+Nginx 的图形化工具 | ★☆☆☆☆ | ✅ **推荐第一步**。不碰命令行，一键建站，还能看到文件目录和数据库 |
| B. 云服务器 + 宝塔面板 | 远端 Linux 一台 + 面板 | ★★☆☆☆ | 迟早要做（S6），但先本地把 WP 玩熟再去 |
| C. XAMPP / phpStudy | Apache+PHP+MySQL 套装 | ★★★☆☆ | ⚠️ 你 3306 端口已被本机 MySQL 占用，会打架；且要自己建库填 `wp-config.php` |
| D. Docker | 容器 | ★★★★☆ | 你是零基础，先不要 |

> 说明：你本机已有 MySQL 8.0.16 在 3306 跑着。Local 用的是它自己那份 MySQL，
> 安装/建站时若提示端口占用，就在站点设置里换一个端口（如 3307）或先停掉本机 MySQL 服务。

## 三、路线 A 详细步骤（Windows）

**1. 腾空间**
C 盘只剩 8.9G，先去清。Local 本体约 1～1.5G，每个站点约 300～600M。

**2. 下载安装**
官网 `localwp.com` 下载 Windows 版 → 一路下一步 → 安装完打开。
（国内下载慢的话，搜索引擎找"Local by Flywheel 安装包"，注意只从官网/可信镜像下。）

**3. 建一个站点**
`Create a new site` → 站点名（用英文，如 `myblog`）→ 环境选 `Preferred`（PHP 8.x / Nginx / MySQL 8）→
填后台管理员账号密码（**记下来**）→ `Add Site`。

完成后你会得到：
```
站点地址： http://myblog.local
后台地址： http://myblog.local/wp-admin
站点文件： C:\Users\<你>\Local Sites\myblog\app\public     ← 就是 WordPress 根目录
数据库：   工具里点 "Database" 打开 Adminer（网页版数据库管理）
```

**4. 认识三个按钮**
`Open site`（打开前台）、`WP Admin`（进后台）、`Go to site folder`（打开文件目录）。
**现在就去点一次 `Go to site folder`**，对照文件 01 那张目录图看一遍 `wp-content`——这一眼比读十页文档有用。

**5. 登录后台**
用你刚设的账号密码登录 `http://myblog.local/wp-admin`。

**6. 立刻做的 3 个设置**
`设置 → 常规`：站点标题、副标题（就是你博客的名字和一句话简介）、时区选 `Asia/Shanghai`。
`设置 → 固定链接`：选「文章名」。**中文站的重要提醒**：中文标题会生成一长串 `%e5%9b%be...` 这种编码，
建议：要么每篇文章手动把"别名（slug）"填成英文/拼音，要么选「数字」型。目标站用的是英文 slug。

**7. 发第一篇文章**
`文章 → 写文章` → 标题 → 正文输入几段 → 右侧「发布」。
去前台看：文章应该出现在首页列表里。点进去能看详情——**这就是 S2 验收通过**。

## 四、如果你选了路线 B（云服务器 + 宝塔）

先把大方向记住，细节在文件 06 展开：
```
买一台 1核2G 的轻量云服务器（学生机/新用户优惠，国内约 ¥60～120/年）
  → 装 宝塔面板（一行命令，官方文档有）
  → 面板里一键装 LNMP（Nginx + MySQL + PHP）
  → 新建站点 + 数据库
  → 下载 WordPress 中文包，上传到站点根目录，解压
  → 浏览器打开域名，按向导填数据库信息
```
**唯一必须先想清楚的**：国内服务器要求域名先备案（7～20 个工作日）；不想等就选香港/海外服务器。

## 五、装完立刻要做的 12 个"认路"任务

不要急着美化。先在后台逛一圈，把下面 12 件事都点一遍（每件 30 秒）：

1. `仪表盘`：看到"站点健康"和 WP 版本号了吗？记下版本。
2. `文章 → 所有文章`：默认那篇 "Hello world!" 在不在？删掉它。
3. `媒体 → 库`：上传一张图片试试（这就是"媒体库"）。
4. `页面 → 所有页面`：默认的"示例页面"在不在？
5. `评论`：能看到待审核评论吗？
6. `外观 → 主题`：现在启用的是哪个主题？记下名字。
7. `外观 → 菜单`：菜单位置有哪几个？（对应顶栏/侧栏）
8. `插件 → 已安装插件`：默认装了什么（Akismet / Hello Dolly）？
9. `用户 → 个人资料`：改一下"公开显示名"和"个人简介"。
10. `工具 → 站点健康`：PHP 版本、MySQL 版本分别是多少？
11. `设置 → 阅读`：首页显示"最新文章"还是"固定页面"？
12. `设置 → 讨论`：评论需不需要审核？

**为什么要做这个**：WordPress 后台只有 9 个主菜单，但新手 80% 的困惑来自"不知道功能在哪"。
这 12 个任务做完，你就有后台地图了。

## 六、常见坑（第一次装必踩）

| 现象 | 原因 | 解法 |
|---|---|---|
| 站点打不开，提示找不到 `myblog.local` | 域名解析靠 hosts 文件，Local 会自动写；被安全软件拦了 | 关掉安全软件的"网页防护"重试；或重启 Local |
| 建站时提示 3306 被占用 | 你本机 MySQL 在跑 | 站点设置里改端口，或临时停 `MySQL80` 服务 |
| 后台很慢、加载不出图片 | 访问了 Google 字体/头像等境外资源 | 装"禁用 Google 字体"类插件，或换海外服务器 |
| 上传主题提示文件过大 | PHP 上传限制 | 先改 `php.ini` 的 `upload_max_filesize`，或用 FTP 上传 |
| 改完设置前台没变化 | 浏览器/插件缓存 | Ctrl+F5 硬刷新；找缓存插件清缓存 |
| 一片白屏 | PHP 报错被隐藏 | 在 `wp-config.php` 里把 `WP_DEBUG` 设为 `true` 看报错原文 |

## 验收（做完告诉我这四项）

1. 你的站点地址与后台地址各是什么？
2. `Go to site folder` 打开后，`wp-content` 下能看到哪几个目录？
3. `工具 → 站点健康` 里，PHP 和 MySQL 的版本号是多少？
4. 你发的那篇文章的固定链接长什么样？（贴 URL 给我）
