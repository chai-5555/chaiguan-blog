# 05 · 第五天：前端最小必修课（只学有用的那 20%）

> 目标：能自己定位"这里差了 4px"并改掉，不再求人。
> 验收：独立把卡片圆角改一次、把某段文字颜色改一次，并能说出改的是哪条规则。

## 一、先建立信心：你要学的比想象中少

| 你想要的效果 | 实际需要的知识 |
|---|---|
| 换颜色、改圆角、调间距 | CSS 变量 + 盒模型 |
| 左右两栏、卡片对齐 | Flexbox（一个属性组） |
| 手机上别挤成一团 | 媒体查询（一个 `@media`） |
| 悬停变色、淡入 | `transition`（一行） |
| 点按钮弹窗 | JS 的 `addEventListener`（读懂即可，会改参数） |

**不需要**：手写整页 HTML、学框架（React/Vue）、学构建工具。你是在"改装一台现成的车"，不是造车。

## 二、开发者工具（DevTools）：你未来 80% 的时间在这里

Chrome 里按 `F12` 或 `Ctrl+Shift+I`。四个面板够用一辈子：

| 面板 | 干什么 | 怎么用（以目标站为例） |
|---|---|---|
| **Elements 元素** | 看 HTML 结构、改样式、立刻看效果 | 点左上角"箭头"图标 → 点页面上的卡片 → 右侧 Styles 里就能看到 `.card` 的规则，勾掉/改数值立刻生效 |
| **Computed 计算样式** | 看元素**最终**生效的每个值 | 你想知道"这个圆角到底几 px"，看这里最准（8px） |
| **Network 网络** | 看加载了哪些文件、多大、多久 | 排查"图为什么不显示""为什么这么慢" |
| **Device 设备模拟** | 切手机尺寸 `Ctrl+Shift+M` | 检查移动端排版 |

**三个必须会的小动作**：
1. 在 Elements 里选中元素后，`Styles` 面板顶部有个 `filter`，输入 `border-radius` 直接搜。
2. 改数字时用 **↑↓ 方向键**，可以实时预览 +1px/-1px，比反复输入快。
3. 改完刷新就没了——**DevTools 里改是"试衣间"，要留下必须写进子主题 CSS**。

## 三、CSS 必会 8 个概念（每个都配站点里的真实例子）

### 1) 选择器与优先级
```css
.card           { }   /* 类：最常用 */
#leftbar        { }   /* id：更"重"，优先级高于类 */
article .card   { }   /* 后代：空格表示"里面的" */
.card:hover     { }   /* 状态伪类：鼠标悬停 */
@media (max-width:900px){ .card { } }  /* 媒体查询里的规则 */
```
优先级：**id > class > 标签**；同权重时**后写的赢**。所以子主题 CSS 加载在父主题之后，就能覆盖。

### 2) 盒模型（90% 的"对不齐"都在这）
```
┌──────────── margin（外边距，推开别人）────────────┐
│ ┌────────── border（边框）──────────┐            │
│ │ ┌─────── padding（内边距）──────┐ │            │
│ │ │        content（内容）        │ │            │
```
`box-sizing: border-box` 让"宽度"包含 padding+border（现代主题默认都有），改了不奇怪。

### 3) Flexbox（一行/一列排列，最常用）
```css
.row { display:flex; gap:16px; align-items:center; justify-content:space-between; }
```
- `justify-content` 管主轴（横排时的左右）
- `align-items` 管交叉轴（横排时的上下）
- `gap` 管间距（比 margin 干净）

### 4) Grid（二维）
```css
.gallery { display:grid; grid-template-columns:repeat(3, 1fr); gap:8px; }
@media (max-width:600px){ .gallery { grid-template-columns:1fr; } }  /* 手机变一列 */
```

### 5) position（把东西"钉"在某处）
```css
.fab { position:fixed; right:20px; bottom:20px; }   /* 右下角浮动按钮 */
.sticky { position:sticky; top:20px; }               /* 滚动到顶就粘住（目标站左侧栏）*/
```

### 6) 媒体查询（响应式）
```css
@media (max-width: 900px) { /* 平板及更窄时生效 */ }
@media (min-width: 1700px) { /* 超宽屏时生效 */ }
```

### 7) CSS 变量（换肤的钥匙，目标站全靠它）
```css
:root { --card-radius: 8px; --themecolor: #fa7298; }
.card { border-radius: var(--card-radius); }   /* 用变量 */
```
改一处 `:root`，所有引用它的地方一起变。**在子主题里覆盖 `:root` 是最安全的改法**。

### 8) transition（动效只需要一行）
```css
.card { transition: all .3s ease; }        /* 任何属性变化都在 0.3 秒内平滑过渡 */
.card:hover { transform: translateY(-2px); box-shadow: 0 8px 16px rgba(0,0,0,.12); }
```
目标站的实测节奏：卡片入场 `.25s ease-out`、标题字距 `.35s`、图片淡入 `.3s`。
**记住这个规律：0.2～0.4 秒、ease / ease-out、位移不超过 8px——这就是"高级感"的配方。**

## 四、30 分钟练习（照着做，做完你就会了）

1. 打开你的站（或目标站），`F12` → 箭头 → 点一张文章卡片。
2. 在 Styles 里找到 `.card`，把 `border-radius` 从 8px 改成 20px → 看变化。
3. 切到 Computed，确认最终生效值。再改 `box-shadow`，试三档。
4. 打开 `Ctrl+Shift+M`，切到 iPhone 尺寸，看你的改动在手机上是否也合理。
5. **把这两个改动写进子主题 style.css**，刷新，确认生效（这一步才是真学会）。
6. 反过来做一次：在 Elements 里**删掉**某个元素的 class，看它变成什么样——理解"样式是靠 class 匹配上去的"。

## 五、PHP 和 JS，你各需要到哪一步

| 语言 | 需要会 | 不需要会 |
|---|---|---|
| PHP | 能看懂 `<?php the_title(); ?>`；会往 `functions.php` 粘贴 `add_action`/`add_filter` 片段并改参数 | 从零写功能、懂面向对象、懂框架 |
| JS | 能看懂 `document.querySelector`、`addEventListener`；会改别人的数值参数 | 写组件、学 React、学打包 |

**学习的正确姿势**：遇到不懂的代码 → 复制给 AI/搜索引擎问"这段在干什么" → 拆成能看懂的最小片段 →
改一个数字看变化。不要去啃语法书。

## 六、复刻目标站时，你会用到的三条实测线索

1. **它没有"魔法"，全是变量**：主题色 4 个变量 → 派生全部表面色。你抄这 4 行就赢了。
2. **动效只有 9 条、都 < 600ms**：所以它"稳"。你不需要更多动画，需要更少但更准的。
3. **最贵的资产是图**：整屏封面必须 2K 以上、色调克制。设计上限 = 封面上限。

## 验收（做完告诉我）

1. 你把卡片圆角改成了多少？改在哪一层（DevTools / 子主题）？
2. 用一句话解释 `transition` 和 `animation` 的区别（提示：触发方式）。
3. 你站的 CSS 里 `--themecolor` 现在是什么值？它的 R/G/B 分量是多少？
4. 手机尺寸下，你的卡片有没有出现横向滚动条？如果有，可能是哪个属性造成的？
