# 03 · 第三天：内容、结构、写作工作流

> 目标：把"发文章"从"随便写点字"升级成"有结构的站"。
> 验收：3 篇文章 + 1 个页面 + 2 个分类 + 1 个导航菜单，且前台归类正确。

## 一、后台 9 个主菜单，一张表说清

| 菜单 | 管什么 | 你会不会常用 |
|---|---|---|
| 仪表盘 | 概览、活动、站点健康 | 偶尔 |
| 文章 | 写文章、分类、标签 | ★每天 |
| 媒体 | 所有上传的图片/文件 | ★常用 |
| 页面 | "关于我""留言板"这类固定页 | ★常用 |
| 评论 | 审核、回复、标记垃圾 | 有读者后 |
| **外观** | 主题、菜单、小工具、自定义 | ★★改观感全靠这 |
| 插件 | 装/停用/删 | ★按需 |
| 用户 | 你自己、作者、权限 | 偶尔 |
| 工具/设置 | 导入导出、站点健康、固定链接 | 装完就设 |

## 二、WordPress 的内容模型（这是整个后台的骨架）

```
文章 post ──┬── 属于若干 分类 category（有层级，像文件夹）
            ├── 带若干 标签 tag（无层级，像关键词）
            ├── 有 作者 / 发布时间 / 特色图片 / 摘要 / 自定义字段
            └── 出现在"首页列表 / 分类页 / 标签页 / 归档页"

页面 page ──── 独立存在，不分类，不进列表（关于、留言板、友链）

菜单 menu ──── 只是"链接的集合"，可指向任何东西，显示在主题规定的位置
小工具 widget ─ 侧栏里的模块（公告、搜索、作者卡…）
```

**一条关键判断**：内容要不要"按时间累积成一列"？
— 要 → 文章。不要（一辈子只改一次）→ 页面。

## 三、区块编辑器（Gutenberg）实操

打开 `文章 → 写文章`，左上角 `+` 就是插入区块。**会这 8 个区块，能写 95% 的文章**：

| 区块 | 用途 | 小技巧 |
|---|---|---|
| 段落 | 正文 | 回车就新建一个；`/h2` 快速插入二级标题 |
| 标题 | 小标题 | **只用 H2/H3**，H1 留给文章标题（SEO） |
| 图片 | 单图 | 记得填"替代文本"（无障碍+SEO） |
| 图集 | 多图排列 | 适合"图寻"这种图密内容 |
| 列表 | 有序/无序 | |
| 引用 | 引一段话 | |
| 代码 | 代码块 | 技术文必备；主题需开代码高亮才有配色 |
| 分栏 | 左右排版 | 移动端会自动堆叠 |

**写好一篇的 5 个动作**：
1. 标题（后面可改，但别频繁改——改了 slug 就变了）
2. 正文分段，段间空一行（不要用一堆 `<br>`）
3. 小标题用 H2 拆开（读者是扫读的）
4. 右侧「文章」面板设置：**特色图片**（= 目标站卡片顶部的缩略图）、**摘要**（列表里的简介）、**分类**
5. 发布前看一眼「固定链接」面板里的 slug

## 四、固定链接：中文站最容易埋雷的地方

`设置 → 固定链接` 推荐用「**文章名**」（`/%postname%/`），然后**每篇文章手动填英文 slug**。

原因：中文标题会变成 `/0%e5%9f%ba%e7%a1%80%e5%b0%8f%e7%99%bd.../` 这种编码串——
能访问，但链接又长又难看，分享出去也不好看。目标站的链接就是英文 slug。

```
好： /wordpress-beginner-guide/
差： /0%e5%9f%ba%e7%a1%80%e5%b0%8f%e7%99%bd%e4%b9%9f%e8%83%bd%e7%9c%8b%e6%87%82/
```

**警告**：站点上线、被搜索引擎收录之后，就不要再改固定链接结构了，旧链接全断。
真要改，得配 301 跳转插件。

## 五、菜单：顶栏那几个按钮怎么来的

`外观 → 菜单` → 新建菜单（如"主菜单"）→ 左侧勾选要加的页面/分类/自定义链接 → `添加到菜单` →
右下 `菜单位置` 勾上"主导航" → 保存。

目标站顶栏 5 个按钮 = **首页 / 文章 / 说说 / 留言板 / 友链**，其中"说说"和"友链"
通常是页面或插件生成的入口——你现在只需要做到：能加 3 个链接并让它们在顶栏出现。

## 六、小工具：侧栏的"公告卡 / 作者卡"从哪来

`外观 → 小工具`，每个主题会注册若干位置（如"左侧栏""页脚"）。
拖一个「文本/自定义 HTML」进去，写你的公告；拖「搜索」进去，就是搜索框。

装了 Argon 主题后（文件 04），侧栏会变成"公告 + 片刻 + 搜索 + 作者卡"的结构，
其中作者卡是主题自带的（读你的头像和简介），**所以先去 `用户 → 个人资料` 把头像（Gravatar）和简介填好**。

## 七、图片规范（决定站点"高级感"的一半）

| 项 | 建议 |
|---|---|
| 封面/特色图 | 宽 1200～2000px，比例 16:9 或 3:2，**文件 < 300KB** |
| 正文内图 | 宽 1000～1400px，导出为 WebP 或 JPG（质量 80） |
| 命名 | 用英文小写+连字符：`kyoto-station-cover.webp`（别用"截图 2026-03-04 21.31.12.png"） |
| 替代文本 | 一句话描述图里是什么 |
| 上传前压缩 | 用 Squoosh / TinyPNG；1000KB 的图压到 150KB 肉眼看不出差别 |

> 目标站那种"整屏插画"的效果，**图片质量就是设计上限**：需要 2K 以上、色调不与主题色打架的图。

## 八、写作工作流（养成后省掉一堆返工）

```
草稿（保存草稿，随时改）
  → 预览（右上"预览"→ 在新标签看前台效果）
  → 定时发布（右侧"发布"→ 立即 → 改成具体时间）
  → 发布后：去前台确认分类/缩略图/摘要都对
  → 发现问题：直接"编辑"，不要删了重发（会换 slug）
```

**修订版本**：WP 会自动存每次保存的历史（`文章 → 编辑器右侧"修订版本"`），改坏了能回退。

## 九、SEO 插件：装一个，别装两个

`Rank Math` 或 `Yoast SEO` **二选一**（两个同时装会互相打架）。
装完只做 3 件事：填站点名/描述、让文章能自动生成摘要、生成 sitemap（`你的域名/sitemap_index.xml`）。
其余选项先别碰——SEO 插件 90% 的功能你用不到。
