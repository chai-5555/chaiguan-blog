# 00 · 学习地图：从零到"你自己的那个站"

> 这份课程按你的真实目标写：**学会 WordPress，最终做出一个 「夕凪の小站」气质的个人博客**。
> 不讲效率，讲"每一步都能自己验收"。你随时可以在任何一节停下，那一节本身就是可用的成果。

## 一、先说你的机器（我实测过）

| 项 | 实况 | 影响 |
|---|---|---|
| 系统 | Windows（C 盘 196G） | 全课程按 Windows 给步骤 |
| 剩余空间 | **C 盘只剩 8.9G（已用 96%）** | ⚠️ 第一件要处理的事，见下 |
| PHP | **没装** | WordPress 跑不起来，必须补 |
| MySQL | 已装 `D:\tool\mysql\mysql-8.0.16-winx64`，**正在 3306 端口跑** | 装环境时别抢这个端口 |
| Node / Python / Git | 都有 | 后面改主题、跑工具用得上 |
| Docker | 有 docker 命令 | 能跑，但概念负担大，不作为第一步 |
| 浏览器 | Chrome | 复刻时用它的开发者工具，够用 |

**先清出空间**：WordPress 本体很小（约 60MB），但本地环境（PHP+MySQL+站点）要 1.5～3G，
再放几个站点、备份、图片，建议至少留 15G。清法：设置→系统→存储→临时文件/回收站/旧版本 Windows；
`C:\Windows\Temp`、浏览器缓存、`%LOCALAPPDATA%\Temp` 通常是几个 G 的大户。

## 二、这门课要同时点亮三条能力线

很多人学 WordPress 失败，是因为把三件事混成一件。其实它们是三条独立的线：

```
A. WordPress 本体  ——  内容怎么组织、主题/插件怎么工作、后台每个开关是干什么的
B. 前端三件套      ——  HTML 结构 / CSS 样式 / JS 行为；你复刻观感时 90% 靠 CSS
C. 部署与运维      ——  域名、服务器、HTTPS、备份、安全；决定"别人能不能访问"
```

学习顺序建议 A → B → C，但 C 的准备工作（买域名/选服务器）可以提前做，因为备案要等。
**不要**一开始三条线同时开——你会同时被三个不同层面的报错击穿。

## 三、六个阶段与验收标准

每个阶段都有一个"不过不算完"的硬验收。**验收不过就别往下走**。

| 阶段 | 内容 | 产出 | 硬验收 |
|---|---|---|---|
| **S1 概念** | 网站怎么跑起来、WP 是什么（文件 01） | 能用自己的话讲清"我打开一篇文章时发生了什么" | 不看文档说出 5 个环节 |
| **S2 跑起来** | 本地环境 + 装 WP（文件 02） | 本机有了一个能登录的 WordPress | 前台能打开、后台能登录、能发第一篇文章 |
| **S3 会写** | 内容模型、编辑器、菜单、固定链接（文件 03） | 3 篇文章 + 1 个页面 + 2 个分类 + 导航菜单 | 文章能在前台正确归类、出现在菜单对应的列表里 |
| **S4 会改** | 装 Argon、主题选项、子主题改 CSS（文件 04） | 站点外观接近目标站 | 主题色/圆角/封面/侧栏四件都改成了你要的样子 |
| **S5 会看** | 浏览器开发者工具 + CSS 最小集（文件 05） | 能自己定位"这里差 4px"并改掉 | 独立完成一次"卡片圆角 8px→20px"的修改并说出原理 |
| **S6 上线** | 域名、服务器、HTTPS、备份（文件 06） | 一个公网可访问、有证书、有备份的站 | 手机 4G 打开你的域名能看到站点，且能恢复一次备份 |

时间预算：每周 5 小时 ≈ 5～7 周。**S2 和 S4 是掉队高发区**，卡住就把报错原文发给我。

## 四、五条学习纪律（比技巧重要）

1. **先跑通，再理解。** 不要试图先读懂 PHP 再装 WordPress——那会让你三周后还在读手册。
2. **只在必要时装插件。** 插件 = 别人写的 PHP 代码，装 20 个等于给站点装 20 个故障源。
3. **动手前先备份。** 数据库 + `wp-content` 目录。养成习惯的代价是 5 分钟，不养成的代价是重装。
4. **不要在后台"外观→主题文件编辑器"里改主题。** 主题一升级，你的修改**全部消失**。正确做法是子主题（文件 04）。
5. **不要边学边换主题。** 主题是观感的地基，换来换去会让你永远停在"看起来不像"的阶段。

## 五、术语小词典（每个词一句话，卡住就回来查）

| 词 | 一句话解释 |
|---|---|
| CMS | 内容管理系统：把"写文章"和"网页长什么样"分开的工具，WordPress 就是其中之一 |
| 域名 | 你买的"门牌号"，如 `yurucamp.vip`；要付年费，且要指向某台服务器 |
| 服务器/主机 | 存放你网站文件与数据库的电脑；虚拟主机=共用一台，VPS=独占一份资源 |
| DNS 解析 | 把域名翻译成服务器 IP 的地址簿；解析生效一般几分钟到几小时 |
| 备案 | 中国大陆服务器上的站点必须做的实名登记，7～20 个工作日；香港/海外服务器不需要 |
| 主题（Theme） | 决定"长什么样"的一整套模板文件；一个站只能启用一个主题 |
| 子主题（Child Theme） | 依赖父主题的小主题，只放你改的那几行，升级父主题不会被覆盖 |
| 插件（Plugin） | 给站点加功能的独立程序；能加，也能拖慢、能冲突 |
| 钩子（Hook） | WP 留的"插队点"：action=在某个时刻插入动作，filter=在某个值上做修改 |
| 模板层级 | WP 选哪个 PHP 文件来渲染当前页面的一套优先级规则，如文章页优先 `single.php` |
| 固定链接 | 文章 URL 的形式，如 `/hello-world/`；**改一次就要小心**，旧链接会失效 |
| Gutenberg | WP 自带的区块编辑器；一段内容=一个"区块"，图片/标题/按钮都是区块 |
| 小工具（Widget） | 侧栏/页脚里可拖放的模块，如"公告""搜索框""作者卡" |
| 媒体库 | 存所有上传图片的地方；图片被"引用"而不是"绑定"到某篇文章 |
| 缓存 | 把动态生成的页面存成静态 HTML 以加速；改完东西看不到变化，第一件事是清缓存 |
| CDN | 把静态文件分发到离用户近的节点；国内常用又拍/七牛/腾讯云 |
| 伪静态 | 让 `?p=123` 变成 `/hello-world/` 的服务器重写规则；Nginx/Apache 写法不同 |
| 主题选项 | 主题自带的后台设置页；Argon 的叫"Argon 设置"，是本站 80% 观感的来源 |
