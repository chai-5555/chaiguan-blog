# 04 · 第四天：装 Argon，把观感做成目标站那样

> 目标：你的站点在**视觉上**接近 `blog.yurucamp.vip`。
> 验收：主题色、卡片圆角、满屏封面、侧栏四张卡，都是你要的样子。

## 一、先懂主题的三个概念

1. **一个站只能启用一个主题**（外观→主题里点"启用"）。
2. **主题 = 一整套模板文件 + 一堆设置项**。改观感有两条路：
   - 后台的「主题选项」（安全，但受限）
   - 子主题里写 CSS（万能，但要会一点前端 → 文件 05）
3. **永远不要直接编辑父主题文件**（外观→主题文件编辑器）。主题一升级，你的修改全部蒸发。

## 二、装 Argon

目标站用的是 **Argon 1.3.5**（作者 solstice23，开源）。两种装法：

```
方法1：外观 → 主题 → 添加新主题 → 搜索 "Argon" → 安装 → 启用
方法2（搜不到时）：GitHub 搜 solstice23/argon-theme → 下载 zip
       → 外观 → 主题 → 添加新主题 → 上传主题 → 选 zip → 立即安装 → 启用
```

启用后会多出 **「Argon 设置」** 菜单（在左侧或"外观"下）。**这就是本站 80% 观感的来源。**

## 二·五、先把目标站的"设计配方"抄下来

这些是我从目标站源码里实测出来的值，你照着调就能得到同样的气质：

| 目标站的效果 | 实际机制（实测） | 你该怎么做 |
|---|---|---|
| 全站粉色调、卡片带粉 | 主题色 `#fa7298` + 表面色由它混合白色派生 | Argon 设置里把主题色改成这个粉，或改成你自己的色 |
| 首屏一整屏插画 | `banner-as-cover`（banner 高度 100vh） | 开"封面图/全屏封面"相关选项，并上传一张竖幅或方图 |
| 滚动后封面变固定背景 | `immersion-color` 沉浸式 | 开启"沉浸式色彩" |
| 顶栏半透明毛玻璃 | `toolbar-blur` | 开启"工具栏毛玻璃/模糊" |
| 文章页标题压在缩略图上 | `article-header-style-1` | 文章页样式选第 1 种 |
| 卡片圆角 8px、轻阴影 | `--card-radius:8px` + 浅阴影 | 圆角设 8，阴影选"浅阴影" |
| 跳转不整页刷新 | pjax（配置 600ms） | 开"PJAX/无刷新加载" |
| 图片滚到才淡入 | lazyload 阈值 800px fadeIn | 开"图片懒加载" |
| 右下角一列浮动按钮 | 主题自带 FAB | 开"浮动操作按钮" |
| 首页一列文章流 | `waterflow_columns:1` | 列表布局选单列 |

> 选项名以你装的主题实际显示为准（同版本的翻译可能略有差别）。
> 一个都找不到就去"外观→自定义"里翻，或把设置页截图发我，我告诉你点哪个。

## 三、把侧栏做成目标站的样子

目标站左侧四张卡，来源各不相同：

| 卡片 | 怎么来 |
|---|---|
| 公告（粉底白字） | 小工具：拖一个「文本」到左侧栏，Argon 会给它加"公告"样式（或主题有专门的"公告"小工具） |
| 片刻 | 主题的"说说/片刻"模块；没有就用「文本」小工具写一句话 |
| 搜索框 | 小工具：「搜索」 |
| 作者卡（头像+三个计数+图标入口） | **主题自动生成**，数据来自 `用户→个人资料`（头像、简介）+ 站点统计 |

所以：**先去补个人资料**（公开显示名、个人简介、头像），侧栏才会有"人味"。
头像走 Gravatar：用同一个邮箱在 gravatar.com 注册即可，或者装"简单本地头像"类插件上传。

## 四、子主题：5 分钟建好，从此想改什么改什么

### 1）建目录
在站点文件里进入：
```
.../wp-content/themes/
└── argon-child/          ← 新建这个文件夹
    ├── style.css
    └── functions.php
```

### 2）style.css（这段"注释"就是主题身份证，必须有）
```css
/*
Theme Name: Argon Child
Template: argon
Description: 我的 Argon 子主题
Author: 你自己
Version: 1.0
*/
```
`Template: argon` 必须和父主题文件夹名一致（去 `themes/` 里看实际文件夹名，可能是 `argon`）。

### 3）functions.php（加载父子两套样式）
```php
<?php
add_action( 'wp_enqueue_scripts', function () {
    // 先加载父主题样式
    wp_enqueue_style( 'argon-parent', get_template_directory_uri() . '/style.css', array(), null );
    // 再加载子主题样式（依赖父样式，保证后者覆盖前者）
    wp_enqueue_style( 'argon-child', get_stylesheet_uri(), array( 'argon-parent' ), '1.0' );
}, 20 );
```

### 4）启用
`外观 → 主题` 里出现 "Argon Child" → 启用。前台应该和启用父主题时**一模一样**（说明成功）。

> 如果前台样式崩了：多半是父主题自己也在 enqueue 样式，重复加载导致顺序问题。
> 这时把 functions.php 里父主题那行删掉，只留子主题那行；还不行就把两行都删掉，
> 改成只用 `add_action('wp_head', ...)` 输出 `<style>`。把你的报错发我，我帮你改。

## 五、用 CSS 变量换主题色（关键一课）

目标站源码里，整站颜色是这样派生的：

```css
--themecolor: #fa7298;        /* 唯一强调色 */
--themecolor-R: 250;          /* 它的 R/G/B 分量，单独存 */
--themecolor-G: 114;
--themecolor-B: 152;

/* 表面色 = 主题色与白色按比例混合，86% 表示很淡 */
--color-tint-86: calc(R + (255 - R) * 0.86), ...;
```

**结论**：改主题色时，**四个变量要一起改**，否则底色和强调色会对不上。在子主题 style.css 末尾加：

```css
:root {
  --themecolor:   #7aa2f7;
  --themecolor-R: 122;
  --themecolor-G: 162;
  --themecolor-B: 247;
}
```

保存 → 前台 Ctrl+F5 → 整站变蓝。**这就是"一套色相派生全部表面色"的威力**：
你只改了 4 行，页面底色、卡片、描边、按钮、进度条全跟着变。

（RGB 分量怎么算：Windows 计算器 → 程序员模式 → 输入十六进制 `7A``A2``F7` → 十进制 122/162/247。）

## 六、几个立刻见效的小改（放进子主题 CSS）

```css
/* 1. 卡片圆角变大（先试 16px，喜欢再调） */
:root { --card-radius: 16px; }

/* 2. 标题去掉默认下划线效果、hover 时才有点变化 */
.post-title a { text-decoration: none; }

/* 3. 正文行高放宽，中文更好读 */
.post-content { line-height: 1.9; letter-spacing: .02em; }

/* 4. 移动端字号别太小 */
@media (max-width: 600px) { .post-content { font-size: 16px; } }
```

改一条 → 刷新 → 看变化。**一次只改一条**，不然你不知道是哪条生效了。
