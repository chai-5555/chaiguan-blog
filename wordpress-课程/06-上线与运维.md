# 06 · 第六天：把站点搬到公网（上线与运维）

> 目标：别人用手机 4G 能打开你的域名，有 HTTPS，并且你能把站恢复回来。
> 验收：公网可访问 + 证书有效 + 成功恢复过一次备份。

## 一、上线需要的三样东西

```
1) 域名      年费 ¥30～80（.com/.vip/.top 各不相同）
2) 主机/服务器 虚拟主机 ¥30～100/年；轻量云服务器 ¥60～200/年（学生机常有优惠）
3) 一个能等的时间：国内服务器要备案（7～20 工作日），香港/海外服务器可立刻上线
```

**备案是国内必须过的坎**：域名 + 服务器都在国内厂商 → 必须备案；用香港/海外服务器 → 不需要备案，
但国内访问速度会差一些，且部分国内服务（如微信分享某些能力）会受限。

## 二、三种主机的区别（一次说清，别选错）

| 类型 | 是什么 | 适合谁 | 代价 |
|---|---|---|---|
| 虚拟主机（共享） | 一台服务器切给很多人用，只给你个面板传文件 | 只想写博客、不想运维 | 不能装任意软件、性能受邻居影响 |
| **VPS/轻量云服务器** | 一台虚拟独占机器，root 权限 | ✅ 想学真本事（推荐） | 要自己维护：更新、备份、安全 |
| 托管 WordPress | 厂商帮你管，你只管内容 | 不想折腾、愿多花钱 | 贵，可定制性差 |

## 三、VPS + 宝塔面板：8 步上线

> 为什么用面板：它把"Nginx 配置、PHP 版本、数据库、SSL、备份"变成网页按钮。
> 对零基础来说，这是最快建立全局感的方式。等你熟了再去学命令行。

```
1. 买服务器（选 Ubuntu 22.04 / Debian 12 系统，1核2G 起），记下公网 IP 和 root 密码
2. SSH 登录（Windows 自带 ssh，或面板提供的网页终端）
3. 装宝塔：官网文档有一行安装命令，复制粘贴执行，记下面板地址+账号密码
4. 面板 → 软件商店 → 一键装 LNMP（Nginx 1.24 + MySQL 8 + PHP 8.1）
5. 面板 → 网站 → 添加站点：填你的域名（先解析），同时创建数据库（记下库名/用户/密码）
6. 下载 WordPress 中文包（cn.wordpress.org）→ 面板文件管理上传到站点根目录 → 解压
   （注意：zip 解压出来常是 wordpress/ 子目录，要把里面的文件全选**移到站点根目录**）
7. 浏览器打开你的域名 → 选语言 → 填数据库信息（第 5 步记的）→ 建管理员账号
8. 站点设置 → SSL → Let's Encrypt 一键申请 → 开启"强制 HTTPS"
```

**DNS 解析**（在第 5 步之前做）：域名商后台 → 添加 A 记录 → 主机记录 `@` 与 `www` 都指向你的服务器 IP。
解析生效一般几分钟，用 `ping 你的域名` 看是否返回那个 IP。

## 四、上线后立刻做的 6 件事

| 顺序 | 事项 | 怎么做 |
|---|---|---|
| 1 | 改管理员密码 + 装安全插件 | 密码 16 位随机；插件用 Wordfence 或 宝塔自带防护，**只装一个** |
| 2 | 关掉文件编辑 | `wp-config.php` 加 `define('DISALLOW_FILE_EDIT', true);` |
| 3 | 配备份 | 插件 UpdraftPlus：每周整站 + 每天数据库 → 存到阿里云 OSS/OneDrive 等**站点之外** |
| 4 | 装缓存 | 插件 WP Super Cache / LiteSpeed Cache（看主机支持哪个）；页面缓存 + 浏览器缓存 |
| 5 | 图片压缩 | 装 Smush 或上传前用 Squoosh 手工压（推荐后者，可控） |
| 6 | 打开"固定链接"确认 | 上线后别再改结构，否则所有旧链接失效 |

## 五、备份与恢复（唯一能救命的技能）

**备份什么**：`wp-content`（主题、插件、上传的图片）+ 数据库（文章、设置、评论）。
**存哪里**：**必须存在站点之外**（同一台机器上的备份，机器挂了就一起没了）。

手动备份两条命令（宝塔里也有按钮，但会命令更安心）：
```bash
# 1. 打包站点文件（排除缓存目录）
tar -czf ~/backup-files-$(date +%F).tar.gz -C /www/wwwroot/你的域名/ wp-content

# 2. 导出数据库
mysqldump -u 数据库用户 -p 数据库名 > ~/backup-db-$(date +%F).sql
```
然后下载到本地或同步到对象存储。

**恢复演练**（必须真的做一次，否则等于没备份）：
```
1. 在面板里新建一个测试站点 test.你的域名
2. 上传两个备份文件，解压/导入
3. 修改 wp-config.php 里的数据库信息指向测试库
4. 打开 test.你的域名，确认文章、图片、主题都在
5. 演练完就删掉测试站
```

## 六、出问题时的排查顺序（照这个顺序，别乱试）

```
1. 整站打不开？
   → ping 域名（有响应吗）→ 端口 80/443 通吗 → Nginx 服务在跑吗 → 看 面板/error log
2. 502 / 504？
   → PHP 挂了或超时：面板里重启 PHP；看 PHP 错误日志；多半是某个插件
3. 白屏 / "critical error"？
   → 把 wp-content/plugins 改名，如果能进后台 → 是插件；逐个改回来定位
   → 把 wp-content/themes 里非当前主题改名 → 排除主题
4. "建立数据库连接时出错"？
   → MySQL 没启动 / wp-config.php 里的账号密码或主机名错了
5. 能打开但样式全乱？
   → 浏览器 F12 的 Network 看 CSS 是否 404；多半是 HTTPS 混用（http 资源）或缓存
6. 后台很慢、更新失败？
   → 国内访问 wordpress.org 不稳定；用"更新代理"或手动上传 zip 更新
```

## 七、性能：让"看起来高级"变成"加载也快"

1. **图片是第一大头**：WebP + 宽 1600px 以内 + 懒加载（Argon 自带）。
2. **页面缓存**：装上缓存插件后，首页应该是"秒开"。
3. **静态资源 CDN**（可选）：图片走对象存储 + CDN，小站先把图片压好更划算。
4. **别装 20 个插件**：每个插件都可能加载自己的 CSS/JS。

自查方法：Chrome → F12 → Network → 刷新 → 看 `DOMContentLoaded` 时间与最大那几个文件。

## 八、从本地搬家到线上（三种方式）

| 方式 | 做法 | 适合 |
|---|---|---|
| 插件迁移 | 本地装 All-in-One WP Migration → 导出 `.wpress` → 线上装同插件 → 导入 | ✅ 最省事，注意上传大小限制 |
| 面板远程下载 | 本地导出站点包上传，数据库用 phpMyAdmin 导入 | 文件大、插件被限流时 |
| 命令行 | `rsync` 传文件 + `mysqldump` 导入导出 | 熟了以后最快 |

**搬完必查**：`设置→常规` 里的 URL 是否已改成新域名；固定链接是否保存一次（刷新重写规则）；
所有图片是否显示（数据库里可能还存着 `myblog.local` 的地址 → 用 Better Search Replace 插件批量替换）。

## 验收清单

- [ ] 手机 4G（关 WiFi）打开你的域名，能看到站点
- [ ] 地址栏是小锁（HTTPS 有效），`http://` 会自动跳 `https://`
- [ ] `wp-admin` 能登录，且 `DISALLOW_FILE_EDIT` 已开
- [ ] 有一份存在站点之外的备份，且你**真的恢复过一次**
- [ ] 你知道"整站打不开"时的前三步排查动作
- [ ] 首页 F12 里没有 404 的 CSS/图片资源
